# 5.8 — Add project forms and prepare command handoff

**Status:** Planned  
**Goal:** Complete the guided project create/edit/update workflow while keeping a single business-logic path for future commands.

## Work list

- [ ] Add project create/edit forms for title, category, description, status, optional dates, season/car links, and notes.
- [ ] Add a dated update form for required summary/date and optional status change/notes.
- [ ] Clearly identify required versus optional fields, preserve typed values after validation errors, and provide explicit Save/Cancel.
- [ ] Review project/team/reference context before saving; show concise success feedback and open the new/updated project or return to its list row.
- [ ] Ensure all form actions call the same project services as other application entry points; do not duplicate rules in TUI handlers.
- [ ] Keep form opening and prefill state separable from command parsing so Phase 8 can hand incomplete commands to these dialogs.
- [ ] Add tests for save/cancel, field error recovery, optional links, update status behavior, archived targets, and persistence after reopening the database.

## Acceptance checks

- [ ] Cancel performs no writes; invalid submissions retain user input and append no activity.
- [ ] Successful project/update writes and audit history are atomic and reported clearly.
- [ ] The form offers no progress percentage, generated status, default date, or automatic completion behavior.
- [ ] Future command dispatch can open a prefilled form but will still use the same use case for complete commands.
- [ ] Keyboard/mouse interaction, focus, resize, and empty states follow shared TUI behavior.

## Dependencies / boundaries

- Depends on [5.2](5.2-project-use-cases.md), [5.4](5.4-project-update-use-case.md), [5.6](5.6-project-list-filters.md), Phase 2 form/dialog patterns, and ARCH-07.
- “Command handoff” here means keeping reusable form/action boundaries; actual `:development` routes, help, completion, and menu-command parity tests are Phase 8 work.
- No external attachments or configurable category/status administration is added in this slice.

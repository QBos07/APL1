# 6.5 — Add install, remove, repair, and dispose use cases

**Status:** Planned  
**Goal:** Validate and record non-replacement lifecycle actions through atomic application operations.

## Work list

- [ ] Add install/remove/repair/dispose operations using the lifecycle repository and shared transaction helpers.
- [ ] Validate active-team scope, unit/car references, entered date, and required action-specific fields; allow optional usage, reason, and notes.
- [ ] Require install to identify an explicit car/position and a unit not already fitted elsewhere; do not silently replace an existing fitment.
- [ ] Require remove to resolve the currently recorded unit/fitment; reject repeated removal or a unit not fitted at the requested location.
- [ ] Ensure repair does not change fitment; require disposal of a currently fitted unit to be preceded by removal.
- [ ] Reject installation of a disposed unit and define behavior for archived units/types without deleting historical records.
- [ ] Append lifecycle and activity records atomically; add field-appropriate audit details and failure context.
- [ ] Add unit/integration tests for valid and invalid transitions, empty/unknown history, cross-team references, archive behavior, and rollback.

## Acceptance checks

- [ ] An invalid transition writes neither lifecycle nor activity rows.
- [ ] Install/remove change derived fitment only through append-only history; repair does not change it; dispose cannot leave a fitted unit.
- [ ] No operation infers stock availability or marks an unassigned part “in inventory.”
- [ ] Event, entered date, usage, and reason values are user supplied and optional exactly as documented.
- [ ] Use cases are testable without Notcurses and are shared by forms and future commands.

## Dependencies / boundaries

- Depends on [6.1](6.1-part-type-schema-repository.md), [6.2](6.2-part-unit-schema-repository.md), [6.3](6.3-lifecycle-schema.md), [6.4](6.4-lifecycle-repository.md), ARCH-01, ARCH-05, and the Phase 3 car service.
- Atomic old/new replacement is a separate operation in 6.6.
- No prediction, auto-installation, or stock-count adjustment is added.

# 2.21 — Implement the persistent status bar

**Status:** Complete (2026-11-24)  
**Goal:** Give the bottom row a consistent place for active-team context and concise application feedback.

## Work list

- [x] Render the status bar across the bottom of the terminal using the new geometry.
- [x] Show active team and view context, plus the latest success, warning, or error message when one exists.
- [x] Show a discoverable command hint (for example, `:` for commands) without obscuring the main message.
- [x] Define message lifetime/replacement rules so a stale success does not hide a later error.
- [x] Give error/warning/success states distinct color and textual markers.
- [x] Route status-bar team activation to the same switcher as [2.20](2.20-team-switcher-rail.md); other status text remains informational.
- [x] Add state tests and verify truncation/wrapping at supported terminal widths.

## Acceptance checks

- [x] Active-team identity and current feedback remain visible across tabs and dialogs where space permits.
- [x] The latest error is not silently replaced by an unrelated transient success.
- [x] Narrow status space uses an explicit compact representation and does not split UTF-8 text incorrectly.
- [x] Clickable team status region has an equivalent keyboard action and a hit region rebuilt after resize.
- [x] Message priority/lifetime behavior is deterministic and tested.

## Dependencies / boundaries

- Depends on [2.16](2.16-redesign-layout-geometry.md) and [2.20](2.20-team-switcher-rail.md).
- Long error details still use dialogs; the status bar is not the only error presentation.


## Verification (2026-11-24)

- `src/tui/status.{h,c}` holds the active team, view context, latest message,
  priority protection for errors, textual level markers, UTF-8-safe rendering,
  a compact narrow mode, and hit offsets for the team/command regions.
- The shell renders the status line from the new geometry on every frame and
  keeps the active team/context in sync after team operations and tab changes.
- `tests/tui/test_tui_status.c` covers markers, priority (error is not replaced
  by success), narrow/UTF-8 truncation, and hit widths. The smoke harness
  asserts `Ferrari · Teams` and the command hint in the status bar.
- `ctest --test-dir cmake-build-debug --output-on-failure`: 2/2 tests pass.

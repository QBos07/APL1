## Verification (2026-11-24)

Environment: Ubuntu C23 build (`cmake-build-debug`), Criterion, Notcurses 3,
Python 3, Xvfb, xterm, xdotool. The smoke harness reconstructs the visible
terminal screen from cursor-addressed output so assertions check current state,
not stale log text.

- `./scripts/check.sh`: fresh configure/build/CTest passed.
- `ctest --test-dir cmake-build-debug --output-on-failure`: 2/2 CTest tests
  passed; `apl1_tests` 116/116 Criterion tests, `apl1_tui_tests` 77/77.
- `python3 scripts/smoke_tui.py --app cmake-build-debug/apl1 --timeout 20`
  passed: window bar, vertical tabs (mouse switch), keyboard/mouse dropdowns,
  dialog-based creation of Ferrari/McLaren, rail/status/F2(t) team pickers,
  command cancel, `:view` navigation, incomplete `:team create` form,
  `:team create --name ...` direct creation, `:team switch Ferrari`, failed
  switch isolation, duplicate-name retry, mouse command prompt, resize with an
  open menu and an open dialog, clean exit/relaunch persistence, and an
  `xterm-mono` limited-color relaunch.
- `./scripts/check-format.sh` and `./scripts/check-static.sh` pass.
- ASan+UBSan build in `/tmp/apl1-san`: 2/2 CTest tests pass.
- Terminal interoperability follow-up: keyboard `NCTYPE_RELEASE` events are
  ignored (Kitty/JetBrains-style terminals report press+release), duplicate
  mouse presses within 25 ms are dropped, and late terminal query replies are
  drained after Notcurses initialization so OSC color responses do not appear
  as typed command text. Focus/selection roles use explicit contrast colors
  with `NO_COLOR`/monochrome underline fallback, and row text is clipped to the
  plane width to prevent wrapped/duplicated dialog lines. Dialogs now fill the
  body and draw their frame last, so background text cannot collide with the
  first line and long values cannot overwrite the border. Information,
  confirmation, and error dialogs draw their message once (wrapped from the
  content row), while form/choice dialogs use the compact message row. View
  switching also
  accepts `,`/`.` (with `[`/`]` kept as aliases) for keyboard layouts where
  brackets require a modifier. The smoke harness covers the new keys and a
  compact 40x10 dialog.
- The smoke database is isolated under a temporary `XDG_DATA_HOME`; schema
  version 3, three persisted team rows, and active team Ferrari were verified.

Limitations: the harness uses Xvfb/xterm without a window manager, so resize
uses `xdotool windowsize` plus a wake key; mouse assertions rely on xterm's
character grid. No real hardware terminal was exercised.

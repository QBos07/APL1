# 2.28 — Verify the redesigned shell and Phase 2 interaction parity

**Status:** Not started  
**Goal:** Extend automated/manual verification so the new layout, colors, dialogs, team switcher, and commands work together.

## Work list

- [ ] Extend `scripts/smoke_tui.py` to assert the window/menu bar, vertical tabs, body content, status bar, and active-team rail control.
- [ ] Exercise mouse and keyboard paths for dropdown open/close, tab switching, team switcher, and a dialog cancel/save flow.
- [ ] Exercise ex-style command open/cancel, navigation shortcut, team switch, and team create (partial opens a dialog; complete command executes).
- [ ] Resize with a menu/dialog open and verify layout/hit regions are recalculated and context is preserved.
- [ ] Capture color-capable and limited/no-color behavior where the runner supports it; keep semantic text/focus assertions central.
- [ ] Keep the smoke test isolated with a temporary database and preserve optional logs on failure.
- [ ] Update the Phase 2 verification record with exact commands, test counts, and any environment limitations.

## Acceptance checks

- [ ] Existing unit/integration/TUI tests and the expanded smoke test pass.
- [ ] Menu and command paths reach the same Phase 2 actions and produce the same team state.
- [ ] Active team is visible in the rail and status bar before/after switching.
- [ ] Dialog cancellation makes no write; complete commands execute once; incomplete commands prefill a dialog.
- [ ] Resize does not leave stale panes, menus, dialog content, or mouse hit regions.
- [ ] The interface remains operable without color and without a mouse.

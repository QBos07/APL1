# 2.3 — Add one reusable list/table interaction

**Status:** Done (2026-11-24)
**Goal:** Provide a small reusable widget/state model for browsing selectable rows before building the team switcher.

## Implementation notes (2026-11-24)

- `src/tui/list.{h,c}` models count, selection, first visible row, and viewport
  height. Movement/page/home/end clamp safely and keep selection visible.
- The team screen draws the marker-based focus/selection and explicit empty and
  no-match messages. Mouse row selection, double-click activation, and wheel
  scrolling follow 2.0.2; resize updates the viewport without losing the record.
- The widget receives an array from the caller and performs no SQL or domain
  mutations. Tests: `tests/tui/test_tui_list.c`; mouse workflow is exercised
  manually under xterm.

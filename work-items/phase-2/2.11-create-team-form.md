# 2.11 — Build the create-team form

**Status:** Not started  
**Goal:** Let a first-time or returning user create a team through a guided form with clear validation and confirmation.

## Work list

- [ ] Add a form with required team name and optional notes; do not ask for or seed a season, roster, budget, or opening balance in this slice.
- [ ] Mark required/optional fields and explain name rules.
- [ ] Preserve typed input after a validation error and focus the relevant field.
- [ ] Provide explicit Save and Cancel actions; cancellation must not create a team.
- [ ] Before save, show the team name and active-team context; use the shared create use case.
- [ ] On successful creation, make the new team active, show confirmation, and return to the team detail/overview state.
- [ ] Support keyboard and mouse interaction and test form state transitions without a terminal.

## Acceptance checks

- [ ] A valid form creates exactly one team through the business use case.
- [ ] Validation errors identify the name field and do not clear user input.
- [ ] Cancel/Escape does not create a row or alter the active team.
- [ ] Success selects the new team as active and confirms the outcome.
- [ ] No unentered motorsport/business data is created.
- [ ] Mouse and keyboard users can reach the same form actions.

## Dependencies / boundaries

- Depends on [2.7](2.7-team-create-validation.md), [2.9](2.9-active-team-setting.md), [2.2](2.2-shared-screen-frame.md), and [2.4](2.4-confirmation-error-dialogs.md).
- Does not implement seasons, currency selection, money, or driver roster setup.

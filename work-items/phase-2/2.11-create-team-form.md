# 2.11 — Build the create-team form

**Status:** Done (2026-11-24)
**Goal:** Let a first-time or returning user create a team through a guided form with clear validation and confirmation.

## Implementation notes (2026-11-24)

- The form has required Name and optional Notes with field markers, Tab
  movement, Enter save, Esc cancel, and visible Save/Cancel buttons for mouse
  users. No season, roster, budget, or balance is requested or seeded.
- Validation errors preserve typed values and focus the name or notes field.
  Cancellation creates no row and leaves the active team unchanged.
- Successful creation uses the shared create use case (single transaction),
  makes the new team active, opens its detail screen, and shows confirmation and
  optional next-step guidance. Tests: `test_team_service.c`,
  `test_team_isolation.c`, and the smoke workflow.

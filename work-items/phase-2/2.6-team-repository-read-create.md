# 2.6 — Add team repository create/list/get operations

**Status:** Done (2026-11-24)
**Goal:** Provide the first production persistence API for teams, following the Phase 2 repository ownership contract.

## Implementation notes (2026-11-24)

- `src/db/team_repository.{h,c}` implements create, get-by-ID, list with an
  explicit `include_archived` option, update, and archive. All values are bound;
  every statement is local and finalized on every path.
- Create returns the stored row and stable ID; missing IDs return
  `APL_ERR_NOT_FOUND`; archived rows are returned by ID or explicit list option.
  The repository borrows the connection and never opens/closes it.
- Tests: `tests/integration/test_team_repository.c`, including ordering,
  archives, missing IDs, closed connections, and SQL-special characters.

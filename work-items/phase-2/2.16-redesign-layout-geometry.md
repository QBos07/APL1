# 2.16 — Redesign the shell geometry for the requested layout

**Status:** Complete (2026-11-24)  
**Goal:** Replace the implemented header/body/actions/status arrangement with a window bar, vertical tabs, main body, and bottom status bar.

## Target layout

```text
┌──────────────────────────────────────────────────────────────┐
│ Overview   Settings   Help   About                           │ window bar
├───────────────┬──────────────────────────────────────────────┤
│ Overview      │                                              │
│ Teams         │                 active view                  │
│ People        │                 main body                    │
│ Events        │                                              │
│ Money         │                                              │
│ Development   │                                              │
│ Parts         │                                              │
│ History       │                                              │
│               │                                              │
│ Team: Ferrari │                                              │ team switcher
├───────────────┴──────────────────────────────────────────────┤
│ Ferrari · ready · : for commands · help                       │ status bar
└──────────────────────────────────────────────────────────────┘
```

The active-team switcher is anchored at the bottom of the vertical tab rail; the status bar repeats the active-team name and current feedback. Dialogs overlay the body while leaving global context visible where the terminal size permits.

# 2.10 — Build the team list and switcher screen

**Status:** Done (2026-11-24)
**Goal:** Let the user inspect and switch between team workspaces quickly without changing data merely by browsing.

## Implementation notes (2026-11-24)

- The Teams list uses the reusable list state, marks the active team in the
  header and row marker, shows name/notes/archived state, and keeps browsing
  write-free. `s` is the explicit switch action; Enter opens detail; `a`
  toggles the archived view; `n` opens the create form.
- Switching persists the stable ID through the use case and leaves the list in
  the newly active team's context. Empty, no-active, and archived-selection
  fallback notices are distinct. Mouse row clicks select and double-click opens
  detail; wheel scrolling moves selection.
- Tests: list/navigation state tests plus the create-switch-relaunch smoke run.

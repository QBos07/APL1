# 2.7 — Add team creation validation

**Status:** Done (2026-11-24)
**Goal:** Enforce team-name rules in a business operation that can be called from both menus and commands.

## Implementation notes (2026-11-24)

- `src/domain/team.{h,c}` trims names, rejects null/blank/whitespace-only names
  and over-long input, and trims optional notes without silent truncation.
- `src/app/team_service.c` runs validation before SQL, calls the repository, and
  translates the unique-name constraint into `APL_ERR_CONFLICT`. Validation
  failures insert no row and do not change the active-team setting.
- The TUI keeps typed values and focuses the name or notes field based on the
  error text. Tests: `tests/unit/test_team.c`,
  `tests/integration/test_team_service.c`.

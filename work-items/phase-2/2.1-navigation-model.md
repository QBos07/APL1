# 2.1 — Add the main navigation model

**Status:** Done (2026-11-24)
**Goal:** Represent the current TUI section/screen and navigation transitions independently from Notcurses drawing and business data.

## Implementation notes (2026-11-24)

- `src/tui/navigation.{h,c}` defines all nine requirement sections, their labels,
  the default Teams section, wrap-around next/previous movement, and an
  implemented-section query. It contains no Notcurses, SQL, or team data.
- The shell state holds the current section and screen. Unimplemented sections
  render an explicit placeholder; returning to Teams restores the list/welcome
  state without mutating teams.
- Tests: `tests/tui/test_tui_navigation.c`.

# 2.13 — Build the empty-database welcome flow

**Status:** Done (2026-11-24)
**Goal:** Make first launch understandable and guide the user to enter their own team data.

## Implementation notes (2026-11-24)

- After migrations, an empty team table opens the welcome screen ("Welcome to
  apl1", no teams, Create/Quit). Quit creates no rows.
- Create opens the 2.11 form; success opens the new team's detail screen and
  lists optional next steps (people, seasons, money, events) without creating
  them. Later launches restore the active team and bypass the welcome.
- An all-archived/no-valid-active database shows the list's no-active-team
  message; a stale/archived stored selection uses the deterministic fallback
  notice from 2.9. No sample team/domain data is seeded.
- Tests: initial-migration empty-table checks, service fallback tests, and the
  first-launch/create/quit/relaunch smoke check.

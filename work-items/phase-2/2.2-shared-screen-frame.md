# 2.2 — Draw the shared screen frame

**Status:** Done (2026-11-24)
**Goal:** Establish one consistent visual frame that all Phase 2 screens can fill.

## Implementation notes (2026-11-24)

- `src/tui/frame.{h,c}` owns the header, body, actions, status, and modal overlay
  planes and applies the pure `layout.c` rectangles. It never queries SQLite.
- The header shows section and active-team context (including "(none)"), the
  status plane carries confirmations/errors, and the too-small fallback notice
  is drawn on the standard plane.
- Resize recomputes geometry, resizes/moves planes, and screens redraw from
  current view state. Tests: `test_tui_layout.c`, `test_tui_frame.c`; real
  rendering/resize is covered by `scripts/smoke_tui.py`.

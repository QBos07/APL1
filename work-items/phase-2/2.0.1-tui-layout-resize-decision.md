# 2.0.1 — Decide the TUI plane and resize model

**Status:** Not started  
**Goal:** Make the layout/redraw strategy explicit before replacing the Phase 1 shell with multi-region screens.

## Proposed direction

Use a small set of dedicated Notcurses planes for independently rendered regions (for example, header, main content, footer/status, and modal overlay). On `NCKEY_RESIZE`, recompute layout from the current terminal dimensions and reposition/recreate or resize those planes. Do not use `stdplane_erase` as the general resize/re-layout strategy; reserve the standard plane for the base surface/background.

# 7.8 — Add outcome correction history

**Status:** Planned  
**Goal:** Make corrections auditable and reviewable, including changes between present and missing values.

## Work list

- [ ] Record correction actor/time and before/after values for outcome edits.
- [ ] Use the shared correction operation from single and batch editing paths.
- [ ] Add repository access to correction history in chronological order.
- [ ] Test corrections to/from missing values and failed correction rollback.

## Acceptance checks

- [ ] Each correction retains old and new values without overwriting its audit trail.
- [ ] Missing-to-value and value-to-missing changes are represented accurately.
- [ ] Failed corrections do not partially update the outcome or its history.

# 7.10 — Add event and quick outcome-entry forms

**Status:** Planned  
**Goal:** Provide guided event/session management and single- or multi-driver manual outcome entry.

## Work list

- [ ] Add event/session create and edit forms with optional season/location/notes.
- [ ] Add single-driver outcome entry/edit with only the defined result fields.
- [ ] Add multi-driver entry using [7.7](7.7-batch-outcome-entry.md), with review before save.

- [ ] Users can save partial outcomes without filling every result field.

- [ ] Cancel and validation failure preserve no unintended writes and do not lose form input.

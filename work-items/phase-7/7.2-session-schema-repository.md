# 7.2 — Add user-created session schema and repository

**Status:** Implemented

**Goal:** Store explicitly entered sessions under an event without generating a race weekend.

## Work list

- [x] Add a session record linked to an event with a user-entered label.
- [x] Add migration and repository create/read/list/update operations.
- [x] Enforce event/team scope in repository queries and writes.
- [x] Add persistence, event ownership, and team-isolation tests.

## Acceptance checks

- [x] Sessions exist only when explicitly created and retain their entered label.
- [x] A session cannot be attached to an event outside the selected team.
- [x] Events may have no sessions; no sessions are generated automatically.

## Dependencies / boundaries

- Depends on [7.1](7.1-event-schema-repository.md) and Phase 1 migration/repository foundations.
- Does not model a generated weekend structure or require predefined session types.

# 7.1 — Add user-created event schema and repository

**Status:** Planned  
**Goal:** Persist manually created events scoped to a team.

## Work list

- [ ] Add an event record with team, entered name/date, and optional season, location, and notes.
- [ ] Add migration, repository create/read/list/update operations, and transaction handling.
- [ ] Validate required values and team ownership of optional season references.
- [ ] Preserve entered date and optional values without generating event data.
- [ ] Add migration, repository, validation, and team-isolation tests.

## Acceptance checks

- [ ] Events persist and are listed only within the requested team scope.
- [ ] Season references must belong to the same team; absent season remains valid.
- [ ] Name/date are required; location/notes are optional and not synthesized.

## Dependencies / boundaries

- Depends on Phase 1 migration/repository foundations, Phase 3 team/season records, and shared record metadata conventions.
- Does not create schedules, sessions, drivers, or outcomes.

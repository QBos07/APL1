# 7.11 — Add recorded-value summaries

**Status:** Planned  
**Goal:** Summarize entered outcome data only where the field’s meaning supports aggregation.

## Work list

- [ ] Identify which fields from [7.4](7.4-result-field-set.md) have well-defined summary operations.
- [ ] Add scoped summary queries for supported fields and expose active event/season/date filters.
- [ ] Exclude or explicitly count missing values; never treat missing as zero.
- [ ] Label summaries as based on recorded values and test empty/partial datasets.

## Acceptance checks

- [ ] Each aggregate has documented semantics and a visible scope.
- [ ] Missing values do not distort aggregates and are identified where relevant.
- [ ] No points table, ranking, or implicit scoring is introduced.

## Dependencies / boundaries

- Depends on [7.4](7.4-result-field-set.md), [7.5](7.5-driver-outcome-schema-repository.md), [7.9](7.9-event-session-detail-outcomes.md), and query/filter foundations.
- Does not infer schedules/results or introduce a points system.

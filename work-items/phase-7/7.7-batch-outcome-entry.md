# 7.7 — Add batch outcome-entry operation

**Status:** Implemented

**Goal:** Enter outcomes for multiple drivers in one all-or-none operation.

## Work list

- [x] Define batch input and per-row validation/error reporting.
- [x] Validate all targets, duplicates, references, and supplied values before commit.
- [x] Persist the batch atomically through the same outcome rules as single entry.
- [x] Test invalid-row rollback, duplicate rows, and transaction failure.

## Acceptance checks

- [x] Missing fields remain missing and valid rows use the same validation as single entry.

## Dependencies / boundaries

- Depends on [7.5](7.5-driver-outcome-schema-repository.md), [7.6](7.6-outcome-validation-save-use-case.md), and transaction infrastructure.

# 0.3 — Confirm the initial source layout

**Status:** Not started  
**Goal:** Agree on a small C project layout that separates business rules, SQLite persistence, application coordination, and Notcurses presentation.

## Proposed layout

```text
src/
  app/       application/use-case coordination
  db/        SQLite connection, migrations, repositories
  domain/    business rules and domain types
  tui/       Notcurses screens and input handling
tests/
  unit/        pure business logic and utility tests
  integration/ SQLite-backed tests
  tui/         TUI-specific tests or test notes, when needed
```

This is a proposal to confirm, not a requirement to create every folder immediately. Keep `src/main.c` as the small composition/startup entry point unless implementation gives a concrete reason to move it.

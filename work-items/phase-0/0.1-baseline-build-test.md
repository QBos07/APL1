**Goal:** Establish what the current scaffold can actually configure, build, and test before changing it.

- [ ] Record compiler/CMake versions, commands, pass/fail results, and any missing system dependency or network fetch requirement in this file or the project README.

Suggested commands:

```sh
cmake -S . -B /tmp/apl1-phase0-baseline -DBUILD_TESTING=ON
cmake --build /tmp/apl1-phase0-baseline
ctest --test-dir /tmp/apl1-phase0-baseline --output-on-failure
```

Use a fresh path that does not overwrite the existing IDE/build directory.

## Acceptance checks

- [ ] The configure, build, and test commands and their actual results are recorded.

- [ ] No application behavior or user data was changed by this verification.

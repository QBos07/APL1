# 8.8 — Add complete ledger and budget commands

**Status:** Planned  
**Goal:** Make the Money and Budget windows fully operable through commands, including the ledger workflows missing from the current command goal.

## Work list

- [ ] Add command routes for transaction list, detail/show, date/category/type filters, and the same search/sort controls exposed by Money.
- [ ] Add opening-balance, income, and expense commands with both incomplete-dialog and fully specified direct-execution forms.
- [ ] Add correction, reversal, and replacement-adjustment commands that select an existing transaction unambiguously and hand off to the same review/confirmation flow as the window.
- [ ] Add budget-plan list/show/create/set/edit and report commands for every action exposed by the Budget UI.
- [ ] Support period/category filters and expose the report's active scope; distinguish no plan/no actual and use the same ledger-derived totals as the window.
- [ ] Parse exact amount/currency/date values through shared validators; show team and reporting currency before ambiguous writes.
- [ ] Ensure overspending remains a warning only and does not block a complete expense command.

## Acceptance checks

- [ ] Every action in the Money/Budget parity matrix has a command equivalent or matching dialog handoff.
- [ ] Opening balance, income, expense, correction, and budget-plan writes use their existing application use cases; command handlers contain no SQL or duplicated money rules.
- [ ] Complete commands and window actions produce equivalent ledger, audit, budget, and derived-report results.
- [ ] Invalid precision/currency, ambiguous transactions, failed confirmation, and cancellation produce no partial write.
- [ ] Corrections preserve the original record; budgets remain separate from actuals; linked project/part costs are never double-counted.

## Dependencies / boundaries

- Depends on [8.6](8.6-window-command-parity-inventory.md), Phase 4 money/budget operations and screens, 8.4 money filters, ARCH-06, and ARCH-08.
- No currency conversion, arbitrary balance edits, or command-only money behavior is added.

# 8.10 — Add complete parts commands

**Status:** Planned  
**Goal:** Make the Parts window's register, fitment, lifecycle, history, and cost-link actions available through commands.

## Work list

- [ ] Add list/show/create/edit/archive routes for every part-type and individual-unit action exposed by Parts.
- [ ] Add install, remove, replace, repair, and dispose commands with incomplete-dialog handoff and fully specified routes where safe.
- [ ] Support car/position, date, action, part type/number, and other filters exposed by the Parts window.
- [ ] Add command routes for current-fitment and chronological part-unit/lifecycle detail views.
- [ ] Add command access to any current-fitment summary/report action exposed by the Parts window.
- [ ] Support selection/linking of an existing ledger transaction for a replacement cost; do not create a second financial record.
- [ ] Reuse the window's review and confirmation steps for atomic replacements and ambiguous old/new unit or fitment choices.

## Acceptance checks

- [ ] Every Parts-window action in the parity matrix is command-accessible or opens its matching dialog.
- [ ] Complete lifecycle commands use the same atomic application operations as the window; a failed replacement leaves old fitment/history unchanged.
- [ ] Unknown/unrecorded fitment remains distinct from no part fitted in command output and filters.
- [ ] Ambiguous unit/car/position targets prompt for selection; commands never guess.
- [ ] Linked costs reference one ledger transaction and are not double-counted.

## Dependencies / boundaries

- Depends on [8.6](8.6-window-command-parity-inventory.md), Phase 6 use cases/screens, 8.5 filters, ARCH-05 link policy, and ARCH-08.
- No inventory inference, reliability prediction, or command-only lifecycle transition is added.

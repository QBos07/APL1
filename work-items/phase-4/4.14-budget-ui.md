# 4.14 — Add budget forms and report screen

**Status:** Done  
**Goal:** Let users create/edit their own plans and inspect planned versus actual values in the Money view.

## Work list

- [x] Add a budget list grouped or filtered by the user-selected period and category, with current team/currency visible.
- [x] Add explicit create/edit forms for period, category, planned amount, optional season, and notes; preserve values and show field-level validation.
- [x] Review the plan details and team/currency before save; show a concise confirmation after successful save.
- [x] Add a report view displaying planned amount, actual amount, variance/remaining, and overspend warning with active scope/filter labels.
- [x] Show distinct no-plan, no-actual, no-match, and populated states; do not represent missing plans/actual records as entered zeros.
- [x] Preserve list/report filters on detail/edit return and provide keyboard and mouse routes consistent with shared TUI patterns.
- [x] Add TUI/controller and end-to-end smoke tests for plan save/edit, comparison, overspend warning, and no-plan/no-actual states.

## Acceptance checks

- [x] A plan is never presented as actual spending and does not change the balance.
- [x] Overspending is clearly warned about but remains recordable.
- [x] Currency, period, category, and active team are visible in the report context.
- [x] Cancel writes nothing; validation errors preserve typed values; successful save opens/refreshes the relevant plan/report.
- [x] Menu and form actions use the same plan use case and calculations.

## Dependencies / boundaries

- Depends on 4.8–4.13, shared dialog/form/list patterns, and ARCH-07.
- Money/budget ex-style command routes and richer search remain Phase 8 work.
- No seeded plans/categories, generated periods, or multi-currency conversion.

# 3.3 — Add dated team-driver membership records

**Status:** Not started  
**Goal:** Preserve which team a driver represented during a user-entered time period, even after a roster change.

## Proposed record

- Stable membership ID, team ID, and driver ID.
- Required user-entered start date; optional end date.
- Optional role/seat label and notes supplied by the user.
- System-maintained timestamps.

Each membership period is a separate record; rejoining creates another period rather than rewriting old affiliation. No contract or seat assignment is inferred.

## Work list

- [ ] Add a migration with foreign keys to team and driver, required start date, optional end date, role/notes, and indexes for team/driver/date lookups.
- [ ] Add repository create/list/get/update/end-membership operations, always requiring team scope for team-facing queries.
- [ ] Add a use case that verifies both referenced records exist and that the driver profile is eligible for a new active membership.
- [ ] Validate date format and reject an end date before its start date.
- [ ] Define duplicate/overlapping membership behavior. Initial proposal: permit multiple historical periods, reject an exact duplicate, and do not infer conflicts from optional role labels.
- [ ] Add tests for create, end, rejoin, invalid references/dates, duplicate behavior, and team scoping.
- [ ] Keep membership operations independent of result records; future outcomes can reference the membership ID.

## Acceptance checks

- [ ] A driver can have multiple dated membership periods without prior periods being overwritten.
- [ ] Current-team roster queries include only memberships for that team that have no end date, unless a historical date is explicitly requested.
- [ ] Historical queries can resolve the exact membership by stable ID and date range.
- [ ] Invalid team/driver references and invalid date ranges do not write partial records.
- [ ] Team A cannot list or alter Team B's memberships through a team-scoped operation.
- [ ] The application does not automatically set dates or create a membership when a driver profile is created.

- Driver/profile and membership dialogs are covered by [3.8](3.8-people-views.md).

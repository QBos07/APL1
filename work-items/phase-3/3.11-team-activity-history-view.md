# 3.11 — Add a team-scoped activity history view

**Status:** Implemented (2026-11-24)  
**Goal:** Let the user inspect team create/rename/archive activity and field changes from the History tab.

## Work list

- [x] Add a History body view that reads audit events for the active team by default.
- [x] Display timestamp, action, record type/name, and concise summary; distinguish entered record dates from system audit timestamps.
- [x] Open an activity detail dialog/view showing field-level old/new values when present.
- [x] Add basic filters for action/entity type and date range; show active filters and an empty state.
- [x] Keep archived teams and their history accessible through an explicit team selection/history scope.
- [x] Ensure audit presentation is read-only; no edit/delete action for history rows.
- [x] Add tests for event ordering, team filtering, no-change/create/archive details, and empty state.

## Acceptance checks

- [x] Team create/rename/archive events from 3.6 are visible and link to the correct stable team record.
- [x] Before/after values from 3.7 are readable and omitted when there was no prior value.
- [x] Default history is scoped to the active team; an all-team view requires explicit selection.
- [x] History records cannot be altered from the UI.
- [x] Filters can be cleared and returning from detail preserves the filtered list position.
- [x] The view does not fabricate an activity for records that predate audit support.

## Implementation notes (2026-11-24)

- The History tab loads active-team events plus shared (teamless) driver identity events by default. `A` explicitly switches to all teams; `f`, `g`, and `d` cycle entity, action, and date filters; `c` clears them and restores active-team scope.
- The filter bar is always visible and clickable by mouse; the persistent key-hint row documents the keyboard equivalents. Event rows start below the filter bar, and mouse row mapping uses the same offset as rendering.
- Events display the system timestamp, action, entity, and summary. Enter opens a read-only detail dialog with the action, field-level old/new values, and absent-value markers.
- Seeded activity remains empty; team and Phase 3 reference/membership mutations append events. Filtered list position is preserved because detail is a modal overlay. Archived-team events remain reachable through the explicit all-teams scope.

# 3.12 — Add commands for Phase 3 reference records

**Status:** Implemented (2026-11-24)  
**Goal:** Make driver, membership, season, and car actions available through the Phase 2 ex-style command system.

## Work list

- [x] Add `:driver list`, `:driver new`, and `:driver show <id-or-name>` routes.
- [x] Add `:membership add` and `:membership end` routes scoped to the active team by default.
- [x] Add `:season list`, `:season new`, and `:season select <label-or-id>` routes.
- [x] Add `:car list`, `:car new`, and `:car show <id-or-identifier>` routes.
- [x] Complete navigation/selection commands directly when unambiguous; open prefilled dialogs for incomplete create/update actions.
- [x] Execute fully specified commands directly through the same validation/use case as dialogs; ask the user to choose when names are ambiguous.
- [x] Add command help/completion entries from the shared registry and tests for active-team scoping.
- [x] Add parity tests comparing menu/dialog and command outcomes for each record type.

## Acceptance checks

- [x] Commands cannot bypass domain validation, audit behavior, or database transactions.
- [x] Incomplete commands open the correct dialog with supplied arguments prefilled.
- [x] Complete valid commands execute once and report success; invalid commands write nothing.
- [x] Team-scoped membership/season/car commands default to the active team and identify that scope before a potentially ambiguous write.
- [x] Duplicate names/identifiers resolve to a choice dialog rather than an arbitrary record.
- [x] Command help documents the implemented syntax and does not claim unavailable options.

## Dependencies / boundaries

- Depends on Phase 2 command UI/parser/dispatch redesign items 2.25–2.27 and the corresponding Phase 3 use cases/screens.
- Money, development, parts, and event commands remain in later phases.
- This first command slice is not the final parity target. Phase 8's
  [window-command parity inventory](../phase-8/8.6-window-command-parity-inventory.md)
  and [reference command completion](../phase-8/8.7-team-people-reference-commands.md)
  add any reference-window actions not covered here.

## Implementation notes (2026-11-24)

- Added `driver list|new|show`, `membership add|end`, `season list|new|select`, and `car list|new|show` to the shared command registry, help, and completion.
- Complete commands execute through the same services as dialogs. Missing create fields open prefilled forms; ambiguous duplicate driver names open an explicit choice; membership commands default to the active team and state that scope.
- Tests: `test_tui_command.c` and `test_tui_action.c` cover parsing, options, completeness, action mapping, help, and completion. The TUI smoke script exercises direct and form paths.

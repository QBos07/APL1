# 1.4 — Enable and verify SQLite foreign keys

**Status:** Not started  
**Goal:** Ensure every application database connection enforces declared foreign-key constraints.

## Work list

- [ ] Enable `PRAGMA foreign_keys = ON` immediately after opening each connection and before application queries/writes.
- [ ] Read back `PRAGMA foreign_keys` and treat a value other than `1` as a connection initialization failure.
- [ ] Ensure all connection creation paths use the same initialization routine.
- [ ] Add a temporary-database test with a parent and child table and attempt an invalid child insert.
- [ ] Clean up test schema/data after each test.

## Acceptance checks

- [ ] A newly opened application connection reports foreign-key enforcement enabled.
- [ ] An insert violating a foreign key fails through the SQLite API.
- [ ] If enforcement cannot be enabled/verified, connection setup reports failure instead of continuing silently.
- [ ] Existing open/close tests still pass.

## Dependencies / boundaries

- Depends on [1.2](1.2-database-connection.md).
- Do not rely on foreign keys as the only place business-rule validation occurs.

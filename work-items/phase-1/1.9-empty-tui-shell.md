# 1.9 — Replace the placeholder with an empty TUI shell

**Status:** Not started  
**Goal:** Prove the application can display a minimal Notcurses screen and exit cleanly before adding domain screens.

## Work list

- [ ] Remove the placeholder “Hello, World!” output from the application entry point.
- [ ] Display the application name and a brief honest empty/scaffold state; do not imply that a team or records already exist.
- [ ] Show a visible exit/help affordance. Do not make an obscure key binding the only way to quit.
- [ ] Handle terminal resize without crashing or drawing outside the available area.
- [ ] Route screen shutdown through the lifecycle from [1.8](1.8-notcurses-lifecycle.md).
- [ ] Keep this screen deliberately temporary and small; the first-run/team flow belongs to Phase 2.

## Acceptance checks

- [ ] Running in an interactive terminal displays the shell and accepts an exit action.
- [ ] Exiting restores normal terminal input/display state.
- [ ] Resizing the terminal does not crash or leave stale terminal state.
- [ ] The screen contains no seeded/sample team or generated business data.
- [ ] A non-interactive launch failure is reported cleanly instead of hanging or corrupting terminal state.

## Dependencies / boundaries

- Depends on [1.8](1.8-notcurses-lifecycle.md).
- Does not implement navigation, team management, database initialization, or command entry.
